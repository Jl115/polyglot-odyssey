## 📖 Theory

### Specification

**Name:** `dev-hint-agent-server` — a FastAPI wrapper around the Day 40 agent pipeline that accepts `POST /ask {"question":"..."}`, runs the LangGraph workflow synchronously, and returns `{"answer":"...","trace_url":"...","iterations":N,"cost_usd":X}`.

### FastAPI server

```python
from fastapi import FastAPI
from pydantic import BaseModel
from agent import app as graph   # your Day 40 graph
import os

api = FastAPI()
class Ask(BaseModel):
    question: str

@api.post("/ask")
def ask(req: Ask):
    result = graph.invoke({
        "question": req.question, "iterations": 0, "kind": "",
        "context": [], "draft": "", "critique": "", "final": ""
    })
    return {
        "answer": result["draft"],
        "iterations": result["iterations"],
        "trace_url": f"https://smith.langchain.com/projects/{os.environ.get('LANGSMITH_PROJECT','day45')}",
    }

@api.get("/healthz")
def healthz(): return {"status": "ok"}
```

### Helm chart additions

- `templates/deployment.yaml` with `livenessProbe: /healthz`, `readinessProbe: /healthz`.
- `templates/qdrant.yaml` as a StatefulSet + Service (persistent volume).
- `secret.yaml` for `ANTHROPIC_API_KEY`, `LANGSMITH_API_KEY` (or a `SealedSecret`).

### Why this matters

Until now everything was local and procedural. This capstone forces you to have a *fully* containerized, *declaratively* deployed, *traced* system — the blueprint for the block capstone (Day 55), which gets a GitHub webhook layer on top.

### Pitfalls

- **Forgot `kind load`** → pod in `ErrImagePull`; set imagePullPolicy `IfNotPresent` since the image is local, not in a registry.
- **Model download in init container:** for large embedding models use an init container, otherwise a crash on every pod start (latency + flaky download).
- **Empty LangSmith API key** → tracing does *not* fail loudly, but spans are missing. The healthcheck should check tracing, not just HTTP.
- **Qdrant StatefulSet without PVC** → restarts wipe the collection. Set `volumeClaimTemplates`.
- **Service port vs. container port** mismatch → pod runs, service returns 503. `targetPort` must be the container port.

## 🛠️ Practice

**Task:** Full deployment story: Docker image, Helm chart, ArgoCD app, curl test with a trace URL in the response.

**Step by step:**

1. Project structure:
   ```
   day45/
   ├── server.py, agent.py (from Day 40)
   ├── Dockerfile
   ├── requirements.txt
   └── charts/dev-hint-agent/
       ├── Chart.yaml, values.yaml
       └── templates/{deployment,service,qdrant,secret}.yaml
   ```
2. Build image + load into kind (snippets above).
3. Develop the chart:
   ```bash
   helm lint charts/dev-hint-agent
   helm template test charts/dev-hint-agent | kubectl apply --dry-run=client -f -
   ```
4. Install:
   ```bash
   helm install dev-hint charts/dev-hint-agent -n ai --create-namespace
   kubectl -n ai rollout status deployment/dev-hint-agent
   ```
5. Port-forward and test:
   ```bash
   kubectl -n ai port-forward svc/dev-hint-agent 8080:8080
   curl -X POST localhost:8080/ask -H 'Content-Type: application/json' \
        -d '{"question":"What is io_uring?"}'
   # → {"answer":"...","iterations":2,"trace_url":"..."}
   ```
6. Create the ArgoCD Application, enable `syncPolicy.automated`. Bump the image tag in `values.yaml` from `0.1.0` to `0.1.1`, commit → ArgoCD sync → rolling update visible.
7. Rollback demo: `kubectl -n ai rollout undo deployment/dev-hint-agent`.

**Definition of Done (DoD):**

- [ ] `kubectl -n ai get pods` shows `dev-hint-agent-...-xxx 2/2 Running` and `qdrant-0 1/1 Running`.
- [ ] `curl localhost:8080/healthz` returns `{"status":"ok"}`.
- [ ] `curl -X POST localhost:8080/ask -d '{"question":"What is io_uring?"}'` returns JSON with `answer`, `iterations`, `trace_url`.
- [ ] The LangSmith trace is reachable and contains all 5 nodes.
- [ ] ArgoCD shows Application `dev-hint-agent` as `Synced` and `Healthy`.
- [ ] A commit on `values.yaml` (image tag) triggers a rolling update visible in `kubectl get pods -w`.
- [ ] `kubectl rollout undo` brings back the old version.
- [ ] Commit: `git commit -m "day45: mini-capstone k8s deployment with gitops"`.

**Extension (optional):** Add a `HorizontalPodAutoscaler` that scales up to 5 replicas on CPU > 70%. Load test with `vegeta` or `hey`: 50 RPS for 30s → observe HPA scaling.
