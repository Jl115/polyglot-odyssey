## 📖 Theory

*"Garbage in, garbage out"* applies to LLMs more drastically than to classic ML: a bad 1000-example dataset is beaten by a good 100-example dataset. **Dataset curation** is the process that turns raw data into *trainable*, *evaluable* examples.

### Pipeline stages

1. **Collect** — from APIs, repos, web scraping, existing datasets (HF Datasets, OpenAssistant, Dolly).
2. **Deduplicate** — exact (`hash`), near-identical (MinHash, SimHash), semantic (embedding clustering).
3. **Filter** — length, language, toxicity, PII (personal data), format consistency.
4. **Format** — instruction template, chat template, system prompt.
5. **Tokenize** — with the model tokenizer; padding, truncation, attention masks.
6. **Split** — train/val/test stratified; for multitask data, by category.
7. **Push** — to HF Hub (private) or a local cache.

### Hugging Face Datasets + `datasets`

```python
from datasets import load_dataset, Dataset
import datasets

# 1. Load
ds = load_dataset("json", data_files="raw.jsonl")["train"]

# 2. Deduplicate (exact)
ds = ds.map(lambda batch: {"hash": [hash(x) & 0xFFFFFFFF for x in batch["text"]]}, batched=True)
ds = ds.unique("text")  # or groupby + first

# 3. Filter
def is_good(ex):
    t = ex["instruction"]
    return 10 <= len(t) <= 500 and "?" in t or "!" in t
ds = ds.filter(is_good)

# 4. Semantic deduplication via embeddings
from sentence_transformers import SentenceTransformer
emb = SentenceTransformer("BAAI/bge-small-en-v1.5")
vecs = emb.encode(ds["instruction"], normalize_embeddings=True)
# cosine > 0.95 → drop as duplicate (e.g. via sklearn.neighbors)
```

### Quality metrics

| Metric | Method | Threshold |
|---|---|---|
| Length (tokens) | tokenizer | 8 ≤ len ≤ 512 |
| Language consistency | `langdetect` or FastText | `lang == "en"` ≥ 0.9 |
| Toxicity | `detoxify` | score < 0.3 |
| PII leaks | regex (`email`, `phone`, IBAN) | 0 hits |
| Perplexity | small reference model | < 100 (upper bound) |
| Diversity | embedding-cluster entropy | ≥ 0.7 |

### Why this matters

The fine-tuning (Day 46) is only as good as the dataset. Practical experience: a curated 200-row Rust FAQ dataset beats a 2000-row raw scrape on inference quality. *Curation is the lever* for the capstone (Day 55), because the dev tool should learn "your code style" — and "your code" must be cleanly filtered.

### Pitfalls

- **Loading in the driver process** on large datasets → OOM. Use `load_dataset(..., streaming=True)` for > 1M examples.
- **Lambda filter closure bugs:** `ds.filter(lambda ex: threshold > X)` reads `X` at filter time — mutating `X` later has no effect. Pass variables explicitly into the dict.
- **Tokenization caching:** HF caches tokenized datasets by input hash — format changes (e.g. a new template) don't automatically invalidate the cache. Change `num_proc` or `cache_dir`.
- **Test set leakage:** after splitting, the same example text in train and test (semantically) → eval metrics are inflated. Deduplicate *before* splitting, check semantically.
- **PII filter too weak:** regex misses `john . doe @ gmail . com` (with spaces). More robust: `presidio` or an LLM filter.

## 🛠️ Practice

**Task:** Build a curation pipeline that reduces 500+ raw Q/A pairs (e.g. a StackOverflow scrape or synthetic via LLM) to 200+ clean examples, with metrics and a train/val split.

**Step by step:**

1. Collect raw data:

   ```bash
   pip install datasets langdetect detoxify sentence-transformers
   ```

   Option A — scrape a StackOverflow sub-tag via BigQuery data on HF (`load_dataset("stackoverflow", ...)`).
   Option B — synthetic via LLM: generate 500 examples via the Anthropic API (paid, ~$1).
2. Curation script `curate.py`:
   - Load, `len()`, `langdetect`, filter to English.
   - Deduplicate by `text` hash.
   - Toxicity filter via `detoxify`.
   - PII regex filter (email, phone number).
3. Semantic deduplication:
   - Embeddings via `BAAI/bge-small-en-v1.5`.
   - cosine > 0.95 → drop.
4. Split the dataset into train/validation and write both to JSONL files:

   > **Hints:**
   > - Call `ds.train_test_split(test_size=0.1, seed=42)` for reproducibility.
   > - Write the splits with `ds["train"].to_json("train.jsonl")` and `ds["test"].to_json("val.jsonl")`.
5. Print statistics so you can verify the pipeline reduced the data as expected:

   > **Hints:**
   > - Print raw count, filtered count, and the sizes of `ds['train']` and `ds['test']`.
   > - Also print the average instruction length in tokens (use the model tokenizer to count).
6. Push to HF Hub (private): `ds.push_to_hub("you/rust-faqs", private=True)`.

**Definition of Done (DoD):**

- [ ] `train.jsonl` and `val.jsonl` exist with together ≥ 200 examples.
- [ ] `curate.py` logs `raw_count`, `filtered_count`, `removed_by_each_step` (hash dedup, language filter, toxicity filter, PII filter, semantic dedup).
- [ ] No example with a PII regex hit in the final dataset.
- [ ] All examples satisfy the length condition (8–512 tokens via the model tokenizer).
- [ ] Train/val have no shared example texts (`set(train) ∩ set(val) == ∅`).
- [ ] Commit: `git commit -m "day47: dataset curation pipeline with metrics"`.

**Extension (optional):** Use a small reference LLM to compute the perplexity of every example — drop the top 5% highest perplexity (outliers).
