### Webhook signature verification

GitHub signs webhooks with HMAC-SHA256 over the payload; the secret is configured in the repo settings.

```python
import hmac, hashlib

def verify_signature(payload: bytes, signature: str, secret: str) -> bool:
    expected = "sha256=" + hmac.new(secret.encode(), payload, hashlib.sha256).hexdigest()
    return hmac.compare_digest(signature, expected)

@api.post("/webhook")
async def webhook(req: Request, x_hub_signature_256: str = Header(...)):
    body = await req.body()
    if not verify_signature(body, x_hub_signature_256, GITHUB_SECRET):
        raise HTTPException(401, "invalid signature")
    event = json.loads(body)
    if event["action"] in ("opened","synchronize"):
        await process_pr(event["pull_request"])
    return {"status": "ok"}
```

### PR analysis pipeline

```python
async def process_pr(pr):
    diff = await fetch_diff(pr["number"])             # GitHub API
    relevant = await qdrant.search(                   # RAG
        embedder.encode(pr["title"]).tolist(), limit=4)
    review = await graph.ainvoke({
        "question": pr["title"], "iterations": 0,
        "context": [r.payload["text"] for r in relevant],
        "draft": "", "kind": "code", "critique": "", "final": ""
    })
    if review["iterations"] < 2:    # self-review loop
        code_test_result = wasm_sandbox.test(diff)    # Day 43
        if not code_test_result["compilable"]:
            review["draft"] += f"\n\n⚠️ Code not compilable: {code_test_result['reason']}"
    await post_review(pr["number"], review["draft"])   # GitHub API
```

### Why this matters

This is the conclusion of the block: you have a *working* AI dev tool that reacts to real GitHub events, analyzes real code, sandbox-tests it, and reviews it — all on your own infrastructure. Even if the quality is "ok" rather than "great", you have demonstrated full-stack competence.

### Pitfalls

- **Skip webhook signature verification** → anyone can call the endpoint and post fake reviews. *Mandatory.*
- **GitHub API rate limit:** 5000/h authenticated; on large repos with many PRs you hit it fast. Use ETag caching.
- **LangGraph sync in the webhook** blocks the response → use `async` and a background task; GitHub expects 200 within 10s.
- **WASM sandbox failures silent** → sandbox crash = no review. Communicate failures explicitly in the comment.
- **Secret tokens in the review text** — the LLM might reproduce code quoted from the PR that contains tokens. Sanitize output via a PII filter (Day 47).
- **No HITL** → auto-review without human override on big PRs can annoy. "Draft mode" for > 500 lines.
- **Model card drift:** after every fine-tune the model card must be re-evaluated (Day 54) — otherwise it's stale.

**Task:** Implement `dev-hint-github-bot` end-to-end: webhook endpoint, PR processing, GitHub posting, deployed via Helm/ArgoCD, with a fairness card and live monitoring.

**Step by step:**

1. Create a test repo on GitHub (`you/test-pr-bot`), set a webhook to your service URL (`/webhook`), generate a secret.
2. Project structure:
   ```
   day55/
   ├── server.py (FastAPI + webhook + process_pr)
   ├── agent.py (LangGraph from Day 40)
   ├── sandbox.py (WASM runner from Day 43)
   ├── Dockerfile

   ├── MODEL_CARD.md (Day 54)

   └── .github/workflows/ci.yml (Day 51)
   ```
3. Local smoke test: `ngrok http 8080` → webhook on the ngrok URL → open a PR → the review posts.
4. K8s deploy (Day 45 pattern): `helm install bot charts/dev-hint-github-bot -n ai`; service exposed via Ingress or an ngrok-ingress-controller.
5. Create the ArgoCD Application; enable self-heal.
6. CI pipeline: on push to `main` → test run + Helm upgrade via GitOps.
7. Fairness test (Day 54) in CI as a mandatory gate.
8. Monitoring dashboard (Day 52) for `/webhook` latency, LangSmith traces, GitHub API errors.
9. `MODEL_CARD.md` with real eval values from Day 48.
10. Record a demo: open a test PR → watch the bot review in real time.

- [ ] The webhook endpoint verifies the signature; invalid signature → 401.

- [ ] The review contains RAG sources (`source:` citations from Qdrant).
- [ ] When the code test in the WASM sandbox fails, the review contains `⚠️ Code not compilable`.
- [ ] The LangSmith trace shows all agent nodes and token cost.
- [ ] `kubectl -n ai get pods` shows the bot Deployment `1/1 Running`; ArgoCD `Synced`.
- [ ] `MODEL_CARD.md` and `ethics.md` are part of the release artifact.
