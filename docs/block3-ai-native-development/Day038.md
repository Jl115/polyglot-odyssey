## 📖 Theory

**Retrieval-Augmented Generation (RAG)** extends an LLM with external knowledge without retraining the model. The pipeline has three stages:

1. **Index:** chunk documents → embed → write into a vector DB.
2. **Retrieve:** embed the question → search the top-k most similar chunks via *cosine similarity*.
3. **Generate:** LLM prompt = system + retrieved chunks + question → answer with source citations.

### Vectors and similarity

Embedding models project text into a vector space (typically 384–3072 dimensions). *Cosine similarity* measures angular dissimilarity and is robust to vector magnitude. *Dot product* on normalized vectors is equivalent but faster — Qdrant uses this internally.

### Qdrant: collections, payload, filters

Qdrant stores *points* (id + vector + payload). Collections have metadata indexes, so you can combine `filter={"must":[{"key":"source","match":{"value":"rust-doc"}}]}` with the vector search for *hybrid search* (vector + metadata). Self-hosting runs in a Docker container.

```bash
docker run -p 6333:6333 -p 6334:6334 \
  -v $(pwd)/qdrant_storage:/qdrant/storage \
  qdrant/qdrant
```

### RAG loop in Python

```python
from qdrant_client import QdrantClient
from sentence_transformers import SentenceTransformer

embedder = SentenceTransformer("BAAI/bge-small-en-v1.5")  # 384-dim, CPU-friendly
qd = QdrantClient("localhost", port=6333)

qd.recreate_collection(
    "docs",
    vectors_config={"size": 384, "distance": "Cosine"},
)

def upsert(text, source):
    v = embedder.encode(text)
    qd.upsert("docs", {"id": hash(text) & 0xFFFFFFFF,
                       "vector": v.tolist(),
                       "payload": {"text": text, "source": source}})

def ask(question, k=4):
    qv = embedder.encode(question)
    hits = qd.search("docs", qv.tolist(), limit=k)
    context = "\n---\n".join(h.payload["text"] for h in hits)
    prompt = f"Context:\n{context}\n\nQuestion: {question}\nAnswer (with sources):"
    return llm.invoke(prompt).content
```

### Why this matters

An AI dev tool that comments on GitHub PRs *must* be able to search repo knowledge — codebase, issues, RFCs. A local Qdrant with CPU embeddings runs on any laptop and avoids cloud lock-in. RAG is the bridge between a "static knowledge base" and "LLM generation".

### Pitfalls

- **Chunk size:** too large → the embedding blurs topics; too small → context is lost. Rule of thumb: 256–512 tokens with 50–100 token overlap.
- **Cosine vs. dot:** if you mix embeddings without length normalization (e.g. OpenAI `text-embedding-3-large` with your own model), dot product is wrong — `Cosine` as default is safer.
- **Filter selectivity:** an overly strict metadata filter can hide all relevant vectors. Test `must` vs. `should` clauses.
- **Stale embeddings:** when documents are updated, old points must be deleted (`qd.delete(...)` with a filter on `source`), otherwise RAG answers with outdated content.

## 🛠️ Practice

**Task:** Build a RAG pipeline over a local Markdown directory (e.g. your Block 1 day notes) and answer a question with source citations.

**Step by step:**

1. Start Qdrant (Docker command above). Healthcheck: `curl localhost:6333/healthz` → `"healthz check passed"`.
2. Python environment:
   ```bash
   pip install qdrant-client sentence-transformers langchain-anthropic
   ```
3. Collect 5–10 `.md` files in `./corpus/` (e.g. your Day001–Day020).
4. Write `index.py`: reads all `.md`, splits into 400-token chunks, embeds, upserts into Qdrant collection `docs`.
5. Write `ask.py`: implements `ask()` above; prints question + 4 hits + answer.
6. Example question: *"What is the difference between move and borrow in Rust?"* — the answer must reference Day 1.

**Definition of Done (DoD):**

- [ ] `curl localhost:6333/collections/docs` shows `points_count > 0`.
- [ ] `python ask.py "What is ownership?"` prints an answer that contains at least one `source` citation.
- [ ] With no hits (empty collection) the script prints a clear notice instead of hallucinating.
- [ ] A hybrid query with a metadata filter (e.g. only `source` file `Day001.md`) returns only chunks from that file.
- [ ] Commit: `git commit -m "day38: rag pipeline with self-hosted qdrant"`.

**Extension (optional):** Use *re-ranking* with `cross-encoder/ms-marco-MiniLM-L-6-v2`: first top-20 by vector, then re-rank to top-4 with the cross-encoder — typically +5–10% accuracy.
