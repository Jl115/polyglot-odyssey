## 📖 Theory

**RISC-V** is an open, modular instruction-set architecture (ISA). Unlike ARM/x86, it is license-free — anyone can implement it, even in their own chips. This has made it the standard for academic research, AI accelerators (e.g. SiFive, Esperanto), and edge SoCs.

### The base + modules

RISC-V is modular: a **base integer ISA** (`RV32I` or `RV64I`, 47 instructions) plus optional extensions:

| Extension | Contents | When do you need it? |
|-----------|----------|----------------------|
| `M` | Mul/Div | arithmetic beyond addition |
| `A` | Atomics (LR/SC, AMO) | concurrency, locks |
| `F`/`D` | Single/Double float | floating-point |
| `C` | Compressed (16-bit) | code size (important for edge!) |
| `V` | Vector | SIMD/ML workloads |
| `B` | Bit manipulation | crypto, hashing |

A target is named e.g. `rv32imac` = base + mul + atomics + compressed.

### Registers & calling convention

32 registers (`x0`-`x31`), `x0` is always 0 (zero-register — a clever ISA simplification):

| Register | ABI name | Role |
|----------|----------|------|
| `x0` | `zero` | always 0 |
| `x1` | `ra` | return address |
| `x2` | `sp` | stack pointer |
| `x10-x17` | `a0-a7` | argument registers |
| `x10-x11` | `a0-a1` | also return values |
| `x8` | `s0`/`fp` | frame pointer |

### A simple instruction

```asm
addi a0, zero, 42    # a0 = 0 + 42 = 42
```

Every RISC-V instruction is exactly 32 bits (or 16 with `C`). The base ISA has **only 47 instructions** — making the ISA learnable in days.

### Why this matters

RISC-V is the first open ISA that is becoming practically relevant. It dominates research into AI accelerators (vector extension `V` for ML) and is pushing into edge SoCs (SiFive, Allwinner D1). Anyone building edge systems will run into RISC-V sooner or later — be it as a soft core in an FPGA, as an accelerator subsystem, or as a complete SoC.

### Pitfalls

- **ABI vs. ISA:** the ISA defines bits, the ABI defines the calling convention. `rv32imac` alone does not tell you whether `ilp32` (32-bit ints/pointers), `ilp32f` (soft-float), or `ilp32d` (hard-float) applies.
- **Compressed is optional:** code using `C` does not run on `rv32i`-only cores.
- **The vector extension `V` is wide** (VLENB = 128+ bits) and not implemented everywhere — check the `misa` CSR.
- **Toolchain names:** `riscv64-unknown-elf-gcc` vs. `riscv32-esp-elf-gcc` (ESP32-C3 uses RV32IMC).

## 🛠️ Practice

**Task:** Write a function `sum_to(n: u32) -> u32` in RISC-V assembly that computes `1+2+...+n`, compile with `riscv64-unknown-elf-gcc`, and run it in QEMU.

**Step by step:**

1. Install toolchain + QEMU (macOS/Homebrew):

   ```bash
   brew install riscv-tools qemu
   # or: apt install gcc-riscv64-unknown-elf qemu-system-riscv64
   ```

2. Create `sum.S` (RV64IMAC) — write the `sum_to` function yourself:

   > **Hints:**
   > - The argument `n` arrives in `a0`; the return value goes back in `a0`. Use `.globl sum_to` to export the symbol.
   > - Initialize an accumulator register (e.g. `t0`) to 0 and a counter register (e.g. `t1`) to 1.
   > - Loop: while `n > 0` (`bgt a0, zero`), add the counter to the accumulator, increment the counter (`addi`), decrement `n` (`addi … -1`), and jump back.
   > - When the loop ends, move the accumulator into `a0` (`mv`) and `ret`.
3. Create `main.c` that calls `sum_to(100)` and prints via semihosting `printf`.
4. Compile and link:

   ```bash
   riscv64-unknown-elf-gcc -march=rv64imac -mabi=lp64 -nostdlib -T linker.ld \
       sum.S main.c -o sum.elf
   ```

5. Run in QEMU:

   ```bash
   qemu-system-riscv64 -machine virt -nographic -bios none -kernel sum.elf
   # expected: Sum 1..100 = 5050
   ```

6. Inspect the disassembly: `riscv64-unknown-elf-objdump -d sum.elf | less` — identify `addi`, `bgt`, `ret`.

**Definition of Done (DoD):**

- [ ] `qemu-system-riscv64` starts your binary and prints `5050`.
- [ ] `objdump -d` shows the `addi`/`bgt`/`ret` instructions — you can explain every line.
- [ ] You can decompose `march=rv64imac` into its extensions and say what `M`, `A`, `C` each mean.
- [ ] You deliberately **provoked a missing extension:** compiled with `-march=rv64if` (float) without `F` in the target and observed the assembler error.
- [ ] Commit: `git commit -m "day77: risc-v sum_to in asm + qemu"`.

**Extension (optional):** Open Godbolt (godbolt.org), select RISC-V `rv64gc`, and write a small C program that uses the vector extension `V` (`vsetvli`, `vadd.vv`) — compare instruction count against the scalar equivalent.
