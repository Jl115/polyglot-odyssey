### Axum — ergonomic web framework

Axum (Tokio team) builds on `tower` middleware and `tokio`. Handlers are async functions that take `extractors` as parameters:

```rust
use axum::{Router, routing::post, extract::Json, response::IntoResponse};
use serde::{Deserialize, Serialize};

#[derive(Deserialize)] struct HashReq { input: String }
#[derive(Serialize)]   struct HashRes { hex: String }

async fn hash(Json(req): Json<HashReq>) -> impl IntoResponse {
    use sha2::{Sha256, Digest};
    let mut h = Sha256::new();
    h.update(req.input.as_bytes());
    Json(HashRes { hex: hex::encode(h.finalize()) })
}

let app = Router::new().route("/hash", post(hash));
```

### CORS & Tower middleware

```rust
use tower_http::cors::{CorsLayer, Any};
let cors = CorsLayer::new().allow_origin(Any).allow_methods(Any);
let app = Router::new().route("/hash", post(hash)).layer(cors);
```

### Frontend integration

The TS frontend uses `fetch` for the backend; for pure client-side operations it can optionally use WASM (Day 16) directly in the browser. Trade-off: WASM in the browser = no server hop, but a larger initial load; a backend call = simpler, but a roundtrip.

### Pitfalls

- Forgetting CORS → frontend `fetch` fails. Set `CorsLayer` even in dev.
- `serde` field names must match on the frontend side. Use `#[serde(rename_all = "camelCase")]` if the frontend uses TS camelCase.
- Port conflicts: dev server on 3000, backend on 8080 — configurable via env.
- Do not commit build artifacts (`target/`) to git (see Day 1 DoD).

## 🛠️ Practice

**Task:** Build an Axum backend with `/hash` (POST, returns SHA-256 hex) + a Vite vanilla-TS frontend that shows a text field + button and displays the hash. Deploy locally (`cargo run` + `npm run dev`).

**Step by step:**

1. Backend `backend/Cargo.toml`:

   ```toml
   [package]
   name = "day19_backend"
   version = "0.1.0"
   edition = "2024"

   [dependencies]
   axum = "0.7"
   tokio = { version = "1", features = ["full"] }
   tower-http = { version = "0.6", features = ["cors"] }
   serde = { version = "1", features = ["derive"] }
   serde_json = "1"
   sha2 = "0.10"
   hex = "0.4"
   ```

2. Implement the backend in `backend/src/main.rs`:

   > **Hints:**
   > - Import from `axum`: `Router`, `routing::post`, `extract::Json`, `response::IntoResponse`; plus `serde::{Deserialize, Serialize}`, `sha2::{Sha256, Digest}`, and `tower_http::cors::{CorsLayer, Any}`.
   > - Define `HashReq { input: String }` (`#[derive(Deserialize)]`) and `HashRes { hex: String }` (`#[derive(Serialize)]`) — field names must match the frontend JSON.
   > - `async fn hash(Json(req): Json<HashReq>) -> impl IntoResponse`: build a `Sha256`, `update` with `req.input.as_bytes()`, `hex::encode(h.finalize())`, and return `Json(HashRes { hex })`.
   > - In `#[tokio::main] async fn main()`: construct a `CorsLayer` allowing `Any` origin/methods/headers (so the frontend `fetch` does not hit CORS), build `Router::new().route("/hash", post(hash)).layer(cors)`, bind a `TcpListener` to `127.0.0.1:8080`, and `axum::serve(l, app).await`.
3. Frontend `frontend/`:

   ```bash
   npm create vite@latest frontend -- --template vanilla-ts
   cd frontend && npm install
   ```

4. Implement the frontend in `frontend/src/main.ts`:

   > **Hints:**
   > - Grab the `#text` input, `#go` button, and `#out` pre element via `document.querySelector<HTML...Element>(...)!`.
   > - On click, `fetch("http://127.0.0.1:8080/hash", { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ input: input.value }) })`.
   > - `await r.json()` and read the `hex` field (cast the result as `{ hex: string }`), then write it into the output element. The SHA-256 must match `echo -n "hello" | shasum -a 256`.
5. Add to `index.html`: `<input id="text"><button id="go">Hash</button><pre id="out"></pre>`.
6. Run: Terminal 1: `cd backend && cargo run`. Terminal 2: `cd frontend && npm run dev`.
7. Open `http://localhost:5173`, type text, click "Hash".

**Definition of Done (DoD):**

- [ ] Backend starts without errors on `:8080`.
- [ ] Frontend starts without errors on `:5173`.
- [ ] A click in the frontend returns the correct SHA-256 (verifiable via `echo -n "hello" | shasum -a 256`).
- [ ] CORS is configured (no CORS error in the browser dev console).
- [ ] `target/` and `node_modules/` are not in git staging.
- [ ] Commit: `git commit -m "day19: fullstack memory-safe app"`.

**Extension (optional):** Also compile the hashing code to WASM (Day 16) and offer a "Server vs. Browser" toggle in the frontend. Compare roundtrip latency vs. WASM load.
