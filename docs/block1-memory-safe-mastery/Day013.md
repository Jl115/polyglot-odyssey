# Day 13: Generics & Constraints (TypeScript)

**Block:** Block 1: Memory-Safe Mastery · TypeScript Advanced

> **Goal of the day:** You write generic functions and classes with `extends` bounds, conditional types, and mapped types — and understand `infer` for type extraction.

---

## 📖 Theory

### Generic functions & bounds

```ts
function first<T extends { length: number }>(xs: T): T | undefined {
  return xs[Symbol.iterator]().next().value;
}
first("hi");   // T = string
first([1,2]);  // T = number
```

`T extends U` is a constraint: `T` must be assignable to `U`. Without `extends`, `T` is unbounded (`unknown`-like).

### Generic defaults

```ts
function pick<T, K extends keyof T = keyof T>(o: T, k: K): T[K] { return o[k]; }
```

### Conditional types — type-level if

```ts
type IsString<T> = T extends string ? true : false;
type A = IsString<"hi">;   // true
type B = IsString<42>;     // false
```

### `infer` — extract a type from a pattern

```ts
type ElementOf<T> = T extends Array<infer E> ? E : never;
type X = ElementOf<number[]>;   // number
type Y = ElementOf<string[]>;   // string

type Awaited<T> = T extends Promise<infer R> ? R : T;
type R = Awaited<Promise<number>>;   // number
```

`infer` binds a type parameter inside an `extends ? :`. It is the most important tool for advanced utility types.

### Mapped types

```ts
type Readonly<T> = { readonly [K in keyof T]: T[K] };
type Partial_<T> = { [K in keyof T]?: T[K] };
type StringKeys<T> = { [K in keyof T as string]: T[K] };   // remapping
```

TS ships many built-ins: `Partial<T>`, `Required<T>`, `Readonly<T>`, `Pick<T,K>`, `Omit<T,K>`, `Record<K,V>`, `ReturnType<F>`, `Parameters<F>`.

### Template literal types

```ts
type Greeting = `Hello ${string}`;
type Method = `get${Capitalize<string>}`;   // "getFoo", "getBar", ...
type Keys = keyof Foo;                       // union of all keys
```

### Why this matters

Generics + conditional types are TS's "type-level programming". They are the basis for ORMs (type mappings), API client generation (e.g. `tRPC`), builder APIs. In Block 3 you will generate AI API types; these tools are the foundation.

### Pitfalls

- TS generics are resolved at compile time — there are *no* runtime generics (type erasure). `instanceof T` does *not* work (T does not exist at runtime).
- `T extends any` is almost the same as unbounded — but TS treats it subtly differently in distribution over unions. Prefer `T extends unknown` for non-distributive conditionals.
- Conditional types over unions *distribute*: `IsString<string | number>` becomes `IsString<string> | IsString<number> = true | false`. That is either desired or surprising — `(T extends U ? X : Y)` with `T` as a naked variable distributes.
- `keyof T` over an `interface` with index signatures yields `string | number` — surprising.

## 🛠️ Practice

**Task:** Write utility types `DeepReadonly<T>`, `UnwrapPromise<T>`, and a function `groupBy<T, K extends keyof T>(xs: T[], k: K): Record<T[K], T[]>` with full type inference.

**Step by step:**

1. Setup like Day 12 (`tsc`).
2. Implement the following in `src/index.ts`:

   > **Hints:**
   > - `DeepReadonly<T>`: a mapped type `{ readonly [K in keyof T]: ... }` that recurses when `T[K] extends object`, otherwise returns `T[K]` as-is.
   > - `UnwrapPromise<T>`: a conditional type using `T extends Promise<infer R> ? R : T` to extract the inner type (falls back to `T` when it is not a Promise).
   > - `groupBy<T, K extends keyof T>(xs: T[], k: K)`: use `Array.reduce` to accumulate a `Record<string, T[]>`; the key is `String(x[k])`. Use nullish-coalescing assignment (`??=`) to lazily create each bucket.
   > - Add a small demo: an array of objects with a `group` field, call `groupBy(data, "group")`, and `console.log` the result.
   > - Prove `DeepReadonly` works by assigning a value and then attempting a nested mutation — it must be a compile error. Check `UnwrapPromise<Promise<{ ok: true }>>` resolves to `{ ok: true }`.
3. `npx tsc --noEmit`.
4. Prove type safety: `frozen.a.b = 2` should be a compile error.

**Definition of Done (DoD):**

- [ ] `npx tsc --noEmit` without errors.
- [ ] `DeepReadonly` is recursive over objects.
- [ ] `UnwrapPromise<T>` uses `infer R`.
- [ ] `groupBy` infers `T[K]` as the key type.
- [ ] Mutating a `DeepReadonly` value is a compile error (proven).
- [ ] Commit: `git commit -m "day13: generics and constraints in ts"`.

**Extension (optional):** Write `Paths<T>` that generates all dotted paths of an object as a literal type (`"a.b.c" | "a.b.d" | ...`). A classic advanced exercise.
