## 📖 Theory

### The one bug class: ownership ambiguity

Whether C, C++, or Zig in ReleaseFast — the root of almost all memory bugs is: **who owns this block, and when is it freed?**

| Bug | C (Day 21/22) | C++ (Day 23) | Zig ReleaseFast (Day 30) |
| --- | --- | --- | --- |
| Use-after-free | manual, UB | `unique_ptr` prevents | `@setRuntimeSafety(false)` → UB possible |
| Double-free | manual, heap corrupt | smart pointer prevents | possible (manual) |
| Leak | forgotten `free` | RAII cleans up | forgotten `alloc.free`/`arena.deinit` |
| Iterator invalidation | pointer dangling | `vector::push_back` UB | slice stale after realloc |
| Buffer overflow | UB, ASan catches | `at()` throws | `buf[idx]` panic/UB depending on mode |

**Rust's unique feature:** the whole bug class is a compile error. All other languages need discipline + tooling (ASan/Valgrind/refcount).

### The unified abstraction: allocator

- **C:** global `malloc` — invisible, untestable.
- **C++:** global `new`, swappable via `std::allocator<T>`, but rarely done.
- **Zig:** allocator as a function parameter — default pattern.
- **Rust:** `Global` trait, usually implicit via `Box`/`Vec`; custom allocators (Nightly) rare.

Zig is the most consistent approach; Rust has the safety edge, but allocator flexibility is secondary.

### Comparing build systems

| Language | Build tool | C interop |
| --- | --- | --- |
| C | Make, CMake, autotools | native |
| C++ | CMake, Make, Bazel | native |
| Zig | `build.zig` (Zig code) | drop-in `zig cc` |
| Rust | `cargo` | `bindgen` + `extern "C"` |

Zig is build system + compiler in one. Rust's `cargo` is more stable, with a larger ecosystem.

### Pitfalls on review

- **Confusing `unique_ptr` move and Rust `Box` move:** semantically the same, but Rust forbids use-after-move *in the compiler*, C++ only at runtime (debug asserts in libc++).
- **Forgetting Zig `@setRuntimeSafety(false)` globally** → ReleaseFast has all safety off. Always test in Debug/ReleaseSafe first.
- **C padding is compiler/ABI-dependent** — `#pragma pack` is not portable across compilers without an attribute.
