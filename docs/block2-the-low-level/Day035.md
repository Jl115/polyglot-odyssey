## 📖 Theory

Block 2 was compact: C → C++ → Zig → polyglot capstone. Instead of new concepts, today is about **meta-learning**: how do you learn from a learning block? The method:

### 1. Retrospective: what was hard?

Write down per day (21–34):

- Did the code compile on the first try? If not — what was the error?
- Which concept was *unintuitive*? (Most often: borrow checker, comptime, ABI types.)
- Which source helped the most (cppreference / zig.guide / Rust Book)?

### 2. Verify knowledge: the Feynman criterion

Can you explain the concept to a friend in **2 minutes without code**? If yes → understood. If no → gap.

Important concepts to test:

- "Why is `unique_ptr` move-only?"
- "What is padding and why is `struct {char; int; char}` 12 bytes?"
- "Why does Zig take an allocator as a parameter instead of a global malloc?"
- "What is `comptime` and how does it differ from C++ templates?"
- "Why is `pool_alloc` + `pool_reset` faster than `malloc`/`free` per block?"

### 4. Skill transfer: where do I apply this?

- **Rust `unsafe`** blocks for C libraries — you now understand what `unsafe` *allows* (use-after-free potential).
- **Performance engineering** — you know that allocator choice often beats algorithm tuning.
- **Cross-language builds** — `zig cc` as a drop-in GCC for Rust `build.rs`/CI.
- **Capstone (Day 90/91+)** — polyglot systems are possible because you master FFI.

### Why this matters

Anyone who continues without reflection accumulates gaps. Block 3 (AI-Native) radically changes the topic — now is the moment to solidify memory fundamentals, otherwise they get buried in 6 weeks. This is also the basis for Block 5 (Edge & Future Systems: RISC-V, kernel, WASM on edge), where low-level concepts return.

### Pitfalls on assessment

- **Overconfidence:** "I understood it" after a once-compile is often deceptive. The Feynman test exposes it.
- **Selective recall:** you remember the successes (Day 34 runs!) and forget the rough days (Day 25 C++20 compiler issues).
- **Depth vs. breadth:** 4 languages in 15 days is inevitably *breadth*. Real depth only comes from 1–2 weeks of *one* language at a time — that is the Block 6 capstone.
